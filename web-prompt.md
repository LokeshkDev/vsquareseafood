# Build a Premium Seafood Sales + Cloud Kitchen Website

## Project Overview

Create a modern, production-ready website for a **fresh raw fish and seafood sales business**, combined with:

* Fresh raw fish & seafood online shop
* Seafood Cloud Kitchen
* Catering services
* Home delivery
* Fresh seafood ordering

The website should feel like a **real Indian food-commerce/mobile shopping application**, similar in usability and visual hierarchy to platforms such as **Instamart, Blinkit, Zepto, Swiggy, and modern food-commerce websites**.

The goal is NOT to make the website look like an AI-generated template.

It should look like a **professionally designed real-world seafood e-commerce product** created by an experienced UI/UX designer and frontend developer.

# 38. Strict Border Radius Rule

The website must **NOT use excessive rounded UI**.

Use a very subtle, professional radius throughout the design.

### Maximum border radius:

**5px only**

Apply this consistently to:

* Buttons
* Product cards
* Category cards
* Search fields
* Input fields
* Select fields
* Images where appropriate
* Product containers
* Cart items
* Checkout sections
* Promotional banners
* Dropdowns
* Modals
* Tabs
* Filter controls

### Important:

Do NOT use:

* `border-radius: 10px`
* `border-radius: 12px`
* `border-radius: 16px`
* `border-radius: 20px`
* `border-radius: 24px`
* `rounded-xl`
* `rounded-2xl`
* `rounded-3xl`
* Pill-shaped buttons
* Excessively circular cards

The maximum standard corner radius is:

```css
border-radius: 5px;
```

For Tailwind, use the closest equivalent to **5px** or define a project utility/token for exactly 5px.
